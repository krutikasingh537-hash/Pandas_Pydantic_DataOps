---

## Key Features

- **Production Ready**: Clean architecture, high reliability, and minimal external footprint.
- **Zero Config**: Ergonomic defaults for rapid integration into existing production workflows.
- **Battle Tested**: Comprehensive test suite and automated CI pipelines.

## Installation

```bash
# Package manager install:
npm install pydantic-excel-mapper
# or
pip install pydantic-excel-mapper
```
